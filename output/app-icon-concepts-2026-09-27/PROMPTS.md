# Diffy app icon concepts

Generated using the built-in image generation tool. Concept artwork; not installed into the app asset catalog.

## 01-delta-d

Use case: logo-brand. Create ONE premium macOS app icon for Diffy, a native local-first developer app for comparing code and images, reviewing Git changes, annotating reviews, and resolving merges. Brand attributes: clarity, calm confidence, approachable precision. Deliver a single square high-resolution icon, front-on, centered, with a macOS rounded-square tile occupying 90% of image and a quiet neutral outer background. Strong instantly recognizable silhouette at 32px, sparse construction, generous breathing room, polished restrained material depth. No words, captions, labels, watermarks, screenshots, multiple variants, or Apple/GitHub logos. The central symbol should be ownable and usable independently as a marketing logo. Direction 1 — DELTA D: a bold custom lowercase d monogram constructed from two interlocking broad geometric strokes, one warm coral and one cool mint, separated by a crisp narrow negative-space seam. The strokes suggest two versions of the same shape aligning into one d; visually unmistakable letter d, clean circular counter, upright stem. Ink navy tile, softly luminous coral and mint enamel, extremely restrained bevel, precision and warmth. No code symbols or small details.
