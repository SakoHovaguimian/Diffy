## Seti UI reference

The PHP, Python and SQL/database artwork in this release intentionally follows the visual language and palette of the MIT-licensed Seti UI icon set used by VS Code. VS Code compiles Seti's SVG sources into `seti.woff`; this project remains SVG-based and reproduces equivalent optical sizing.
