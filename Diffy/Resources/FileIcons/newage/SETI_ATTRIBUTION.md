# Seti UI attribution

Selected file-icon silhouettes and the compact sizing system in this theme are based on the Seti UI file icon set used by Visual Studio Code.

Source: jesseweed/seti-ui
License: MIT
Copyright (c) 2014 Jesse Weed

The Seti UI project recommends a 32x32 source frame with the icon centered at approximately 18x18. Nyk Symbolic Icons uses that compact optical proportion as its file-icon sizing reference while keeping its custom folder system.

The full Seti UI license is available from the upstream project.
